# RatCast pública

Aquí se publican las versiones de **RatCast pública**, una app para Android.

- Baja la última versión en **Releases** (el archivo `.apk`).
- Para usarla necesitas un código: pídeselo al creador de RatCast.
- Si ya la tienes, se actualiza desde la app: **Descargas › Actualizar app**.
